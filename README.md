# HTML-CSS Projects

A collection of responsive web development projects built using HTML5 and CSS3. These projects were created to strengthen my understanding of front-end fundamentals, responsive layouts, styling, and user interface design.

## Projects

### Amazon Clone
A responsive e-commerce interface inspired by Amazon, built using HTML and CSS.

**Focus:** Navigation bar, product sections, images, layout, footer, and responsive design.

### Login Form
A clean and responsive login page designed using HTML and CSS.

**Focus:** Form structure, input fields, styling, and visual layout.

### Registration Form
A responsive registration page created using HTML and CSS.

**Focus:** Form elements, input styling, layout, and responsive design.

### The Olive Table
A responsive restaurant website designed for a fictional restaurant, The Olive Table.

**Focus:** Restaurant layout, navigation, responsive design, image sections, content sections, and footer.
